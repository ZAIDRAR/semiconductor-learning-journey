# 04 — Verilog and Digital Design

**Status:** Study plan.

## Concepts
- Boolean logic, combinational and sequential modules
- Registers, counters and finite-state machines
- Synthesizable Verilog/SystemVerilog
- Testbenches, waveform inspection and assertions
- RTL simulation and synthesis differences

## First experiment
Implement an 8-bit ALU supporting addition, subtraction, AND, OR and XOR. Define flags and overflow behavior; test boundary cases and save waveforms.

## Suggested tools
Icarus Verilog or Verilator, GTKWave and Yosys.
