# 03 — Analog Circuits, ADC and DAC

**Status:** Study plan.

## Concepts
- Operational amplifiers, comparators and Schmitt triggers
- ADC resolution, sampling and quantization
- R-2R DAC and binary-weighted DAC
- Ramp, successive-approximation and cyclic ADC architectures
- Accuracy, offsets, loading, timing, and noise

## First experiment
Build a 4-bit R-2R DAC in LTspice, sweep the input code, and compare each output with the ideal relationship. Record reference voltage, resistor values, the output load, and the measured step size.

## What to publish
Original schematics, simulation configuration, waveforms, theory and error analysis.
